# CEF binary distribution used by Vibrium.
# Vibrium needs H.264/AAC (most streaming sites), which the official Spotify
# builds lack (CEF issue #3559). The pinned archive is a third-party build of
# the same, unmodified CEF version compiled with
# proprietary_codecs=true ffmpeg_branding=Chrome (github.com/psmux/godwinmix-cef).
# Because it is not in the official index, CI verifies it against the SHA1 AND
# SHA256 pinned below and fails if either is missing or different.
# To go back to the official build: delete CEF_DOWNLOAD_BASE, set
# CEF_DISTRIBUTION=minimal and clear the two hashes (CI then checks the
# official index at https://cef-builds.spotifycdn.com/index.json instead).
# To upgrade: change CEF_VERSION (and CEF_SHA1), then re-verify the CEF APIs
# used under c++/ against the new headers and update THIRD_PARTY_NOTICES.md.
