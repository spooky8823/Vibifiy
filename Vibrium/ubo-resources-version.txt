# uBlock Origin source used to build the scriptlet resources (resources.json).

# Scriptlets are small scripts that neutralise a page's ad logic before it runs
# (for example, they strip the ad data from YouTube's player response). The
# filter lists contain the RULES (which site gets which scriptlet); uBlock
# Origin contains the CODE the rules refer to. CI fetches exactly this commit,
# converts its scriptlets with tools/build_ubo_resources.mjs and packages the
# result as filters/resources.json.
