# Vibrium Version 1

## Added

- Added separate browser profiles, including profile creation, naming, pictures, archiving, deletion, and per-profile data controls.
- Added a customizable new tab page with search engine selection, light and dark themes, custom backgrounds, clock styles, system gauges, website shortcuts, and shortcut folders.
- Added browsing history and downloads pages with searching and controls for clearing or managing recorded items.
- Added an ad-blocking suite with filter-list controls, custom rules, site allowlisting, blocking sessions, and an ad-blocking activity console.
- Added privacy controls for Do Not Track and Global Privacy Control, plus options to clear browsing history and cookies.
- Added Settings sections for Appearance, Ad Blocking, Privacy, Downloads, Updates, Console, and About.
- Added a browser updater that closes Vibrium, downloads the latest CI build, installs it, and reopens the browser.
- Added download options for choosing whether to show Save As for each download.

## Improved

- Improved the profile picker with a responsive interface that supports system light and dark themes and custom profile appearance settings.
- Improved Appearance settings with preset accents, custom colour selection, and resetting to the profile default.
- Improved new-tab shortcut management with drag-and-drop ordering, folders, context actions, and custom icons.
- Improved ad-blocking controls with live summaries, filter update status, cosmetic filtering and scriptlet controls, and resettable defaults.

## Fixed

- Fixed ad-blocking policy changes to refresh the renderer when a policy file changes even if its timestamp is unchanged.
- Fixed profile accent colours and tab-strip colours to remain tied to profile and browser appearance settings instead of the Windows system theme.
